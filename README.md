# 🎵 吟游诗人 · 和弦发声器

QQ 官方机器人的和弦工具：**点两下按钮就能听到和弦**，附构成音、音程与分解型。
声音是实时合成的 8-bit 波形，**不需要安装 ffmpeg**。

> 依赖 [astrbot_plugin_qqofficial_hub](https://github.com/204343414/astrbot_plugin_qqofficial_hub) **v0.17.0 以上**（需要 `send_media_message`）。

## 玩法

```
/吟游诗人        # 打开面板：选根音 → 选和弦 → 出声
/和弦 Cmaj7      # 直接弹一个和弦
/单音 C4 E4 G4   # 直接弹一组音
```

### 记谱规则

**字母后面跟数字是八度，跟字母是和弦。** 这一条规则同时覆盖单音和和弦，不会有歧义。

| 输入 | 含义 |
| --- | --- |
| `C` | 单音 C4（中央 C） |
| `C5` | 单音 C5，高一个八度 |
| `Cmaj` / `C` | C 大三和弦 |
| `Cm` / `Cmin` | C 小三和弦（**小写 m**） |
| `CM` | C **大**三和弦（大写 M） |
| `G7` | G 属七和弦 —— **不是** G 的第 7 八度 |
| `F#m7` / `Gbm7` | 升 F 小七和弦，升降号任写 |
| `1` `5` | 简谱数字，等同 `C` `G` |

支持 12 种和弦：大三、小三、属七、大七、小七、减三、增三、挂二、挂四、加九、大六、小六。

## 音色

四种经典 8-bit 波形，面板上可循环切换：**方波**（默认）、锯齿波、三角波、正弦波。
噪声发生器已就绪（`synth.noise`），留给之后的鼓点。

## 为什么不需要 ffmpeg

**波形就是一串数字**：`sin()` 算出来的数组直接就是音频，WAV 容器只是标准库里的
44 字节头。这就是声音能纯 Python 合成的原因。

ffmpeg 只有做**视频**时才躲不掉——H.264 / AAC 是专利编码器，几十万行 C，
不可能自己写。两者性质完全不同。

| 格式 | 何时使用 | 体积（1.6 秒和弦） |
| --- | --- | --- |
| **silk** | 装了 `graiax-silkcoder` 时（QQ 原生语音格式） | ~16 KB |
| **wav** | 没装时自动降级 | ~100 KB |

> `graiax-silkcoder` **不在 `requirements.txt` 里**，因为它只发布源码包
> （内含 SILK SDK 的 C/C++ 源码），安装时需要现场编译，而 AstrBot 官方镜像
> 没有编译器——写进依赖会导致**整个插件装不上**。
>
> 想要更小的语音，在能编译的环境里手动装：
> ```bash
> pip install graiax-silkcoder
> ```
> 装不上也完全不影响使用，只是语音大一些。

官方文档 `file_type=3` 同时接受 `silk/wav/mp3/flac`，所以降级是**正规做法**而非将就。
`graiax-silkcoder` 自带编码器，同样不需要 ffmpeg。

## 无损的关键

插件只在本地保存**音符序列**，从不保存或拼接已编码的音频。每次播放都从
原始的 float64 数组重新渲染，因此**无论播放多少次都只损失最后一道编码**。

先下载再拼接再重编码的做法，每一轮都在上一轮的劣化上继续劣化——这正是要避开的。

## 卡片与撤回

面板的整条链路（选根音 → 选和弦 → 结果）共用一个会话 `ui:chord:<群>`，
所以每张新卡都会**撤回它替代的那一张**，不会在群里堆一叠。

## 依赖

**唯一的必装依赖是 `numpy`**，而且连它都不是硬性的：找不到 numpy 时会自动切换到
纯 Python 实现（`chord/_purepy.py`），渲染慢一点点，**输出逐字节完全一致**——
不是"另一种音色"，是同一个声音。

这样插件在任何环境都装得上、都出得了声。

## 结构

| 文件 | 职责 |
| --- | --- |
| `chord/theory.py` | 音名、和弦、音程、分解型。纯逻辑，无任何依赖 |
| `chord/synth.py` | 波形、包络、WAV / silk 编码 |
| `chord/_purepy.py` | 没有 numpy 时的兜底实现，输出与 numpy 完全一致 |
| `chord/cards.py` | 卡片布局，严格控制在 QQ 的 5×5 以内 |
| `main.py` | Hub 对接：注册 Action、发牌、发语音、命令入口 |

## 测试

```bash
python -m pytest tests -q
```

音频的 bug 在代码 diff 里看不出来、在音箱里一听就穿帮，所以测例直接**测信号本身**：
方波是否真的只有两个取值、A4 的频谱峰值是否真在 440 Hz、和弦里是否真含每个音的频率、
音符首尾是否归零（否则每个音都会「咔」一声）。
